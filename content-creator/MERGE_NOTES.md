# CollabX merged team project

This archive merges the four submitted team ZIPs into a clean source tree.

Base/source of truth: the latest tested Creator/Auth/standalone-frontend project from submission 3.
Added from submission 1: Creator Reviews + Pricing.
Added from submission 2: Creator Campaigns + Discover + Portfolio support.
Added from submission 4: Brand workflows, Payments, Socket.IO negotiation support and unique frontend components.

Core Creator Request/Negotiation/Collaboration/Profile/Dashboard/Notification implementations were preserved from the tested project.
Creator and Brand module indexes, app/server startup, and authentication middleware were manually merged.

Secrets, node_modules, Git internals, backups and generated dist files are excluded.
